# Release notes

## Changes

- updated dependencies
- Updated the versions of the used images
- Removed the configuration of GitVersion, which is not used anymore
- Added `CultureUtilities.get_cultured_language_from_culture_code` (also reachable via dict-like access, e.g. `CountryInformationCore()["de-AT"]`) to resolve a culture-code (e.g. "de" or "de-AT") into its language and (if available) country
- Added `CulturedLanguage.get_display_name_in_english`, `CulturedLanguage.get_language`, `CulturedLanguage.get_country`, `CulturedLanguage.country_is_available`, `CulturedLanguage.country_is_explicit` and `CulturedLanguage.get_country_or_associated_country`
- Added `Country.flag_emoji` (a flag-emoji-literal for every country) and `CacheForCountries.get_associated_country_by_language_code` (the country usually associated with a language, e.g. "en" -> United States, used as a fallback when a culture-code has no explicit country)
- Fixed that `LanguageUtilities.get_language_from_iso639_1_code` and `LanguageUtilities.get_language_from_code_iso639_3` could resolve to the wrong language when several languages share the same ISO-639-1-code (for example Germany was resolved to "Austro-Bavarian German" and Iran to "Dari" instead of "German" respectively "Persian (Farsi)")
