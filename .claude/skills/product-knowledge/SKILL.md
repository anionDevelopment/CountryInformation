# Product knowledge: CountryInformation

## Generated data-files

`CountryInformation/CountryInformation/CountryData.py` and `CountryInformation/CountryInformation/LanguageData.py` contain generated data
(both start with the comment `# The content of this file is generated.`).
Do not edit these two files by hand, even for a small fix: a manual change contradicts their generated nature and is overwritten again as
soon as they are regenerated. They are generated by `CountryInformation/Other/CommonTasks.py` (function `common_tasks()`), which runs
automatically as part of `scbuildcodeunits`/`task bb`:

1. `get_data_from_submodule()` copies `Other/Resources/Submodules/countries/dist/countries.json` (the mledoze/countries git-submodule) to
   `CountryInformation/Other/Resources/RawData/Countries.json`.
2. `generate_python_data_files()` reads that JSON-file and calls `generate_language_file()`/`generate_countries_file()`, which build and
   write `LanguageData.py`/`CountryData.py` as plain text (using `LanguageCodeConversionUtilities` for the ISO-639-1/-3-mapping).

If the data in one of these files is wrong or incomplete, fix it at its actual source instead:

- If the wrong value comes from the upstream data, fix it upstream respectively update the `countries`-submodule.
- If the wrong value comes from a mapping used while generating these files (for example `LanguageCodeConversionUtilities`), fix the mapping there.
- If the generator-logic itself (`CommonTasks.py`) is wrong, fix it there.
